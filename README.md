# KMZ Exporter & Compare

QGIS plugin that exports layer groups to KMZ or KML with the same point icons and category colors as the map, applies icons and balloons from a reference KMZ, and compares folder counts, names, fields, and coordinates.

- **Page:** https://yuyouhui.online/tools/qgis/kmz-exporter-compare/
- **Download:** https://yuyouhui.online/tools/qgis/downloads/kmz-exporter-compare-1.0.4.zip
- **QGIS:** 3.28 through 4.99 (Qt 5 and Qt 6)
- **Version:** 1.0.4
- **License:** GNU GPL v2 (`kmz_exporter_compare/LICENSE`)
- **Languages:** English, 中文, Español, Français, العربية, Italiano, Deutsch, 日本語, 한국어. The menu shows each name in that language. The first open follows the QGIS interface language, then the choice is remembered.
- **Data:** local project layers and files you choose. This plugin does not download data or sign in to a website.

Install the folder `kmz_exporter_compare` from a release zip, or copy it to `[QGIS profile]/python/plugins/kmz_exporter_compare`. Quit QGIS completely and open it again.

The main window and dialogs are independent taskbar windows with minimize, so you can still drop KMZ files while QGIS is minimized. Home shows five jobs only. Layer panel shortcuts such as clear data and copy layer live in the **Layers Panel Tools** plugin.

Options on the export, manual-style, and coordinate-compare pages are stored only when **Save settings** is clicked.
