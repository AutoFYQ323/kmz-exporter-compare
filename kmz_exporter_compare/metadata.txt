about=One main window with five jobs: group-based KMZ/KML export whose point icons and category colors match the QGIS map (single, categorized, and graduated symbols are written as they appear; export names, display fields, categories, field picker, optional KML); manual or automatic style replacement from a reference KMZ; coordinate compare between an imported KML/KMZ and project layers with drag pairing, auto-match, and tolerance in the project CRS; layer compare for counts, Name values, or point/line/polygon totals with copy and report export. Home toolbar imports or exports settings bundles and can restore default page sizes. Layer utilities clear data, toggle edit mode, or copy the selected layer. UI in English, 中文, Español, Français, العربية, Italiano, Deutsch, 日本語, and 한국어. Names in the language menu stay in each language. The first open follows the QGIS interface language and the choice is remembered. Export, manual-style, and coordinate-compare options are stored only when Save settings is clicked. Local files only; QGIS 3.28 through 4.99 (Qt 5 and Qt 6).
